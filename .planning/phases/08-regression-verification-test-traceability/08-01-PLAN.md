  <name>Define traceability matrix schema</name>
  <files>.planning/traceability-matrix-schema.md</files>
  <action>
Create schema documentation for the traceability matrix per FRD F13 requirements.

**Columns:**
- `finding_id`: Stable ID from baseline-inventory.md (BF-001 through BF-111, format BF-NNN)
- `requirement_ref`: FRD requirement ID (F1.1, F2.3, F7.1, etc.) this finding maps to
- `implementation_ref`: Code location or PR/commit link (populated during implementation phases, empty initially)
- `test_ref`: Test class/method reference (e.g., `UserControllerIntegrationTest::testCreateUser`, `e2e/auth.spec.ts::login flow`, empty initially)
- `status`: Enum [`not_started`, `implemented`, `tested`, `verified`]
  - `not_started`: No implementation or test exists yet
  - `implemented`: Code exists, implementation_ref populated, no test yet
  - `tested`: Test exists and passes, test_ref populated
  - `verified`: Test has passed at least once in CI (production-ready)
- `notes`: Optional free-text (use for Open Question references, edge cases, deferred decisions)

**Status Transitions:**
- `not_started` → `implemented` (when code lands)
- `implemented` → `tested` (when test is written and passes locally)
- `tested` → `verified` (when CI confirms test passes)

**Query Examples:**
```bash
# All findings with no test
grep ',tested\|,verified' traceability-matrix.csv -v

# Coverage by feature
grep 'F7\.' traceability-matrix.csv | cut -d, -f2,5 | sort | uniq -c

# Open findings mapped to requirement
grep 'BF-028\|BF-038\|BF-058' traceability-matrix.csv
```

**Maintenance Rules:**
1. Never delete rows (findings are historical record)
2. Status only moves forward (never regress from `verified` to `tested`)
3. Every F0 Open Question resolution MUST add a test before marking the finding `tested`
4. New findings discovered post-audit get BF-NNN+1 IDs and append to matrix

**1. Create seed script:** `scripts/traceability/seed-matrix.sh`

Script parses `.planning/phases/01-legacy-functional-audit/baseline-inventory.md` and generates CSV:

```bash
#!/bin/bash
set -euo pipefail

INPUT=".planning/phases/01-legacy-functional-audit/baseline-inventory.md"
OUTPUT=".planning/traceability-matrix.csv"

echo "finding_id,requirement_ref,implementation_ref,test_ref,status,notes" > "$OUTPUT"

# Skip header rows (lines 1-11), parse data rows starting line 12
tail -n +12 "$INPUT" | grep -E '^| BF-[0-9]{3}' | while IFS='|' read -r _ id _ _ desc status maps_to _; do
  # Trim whitespace
  id=$(echo "$id" | xargs)
  desc=$(echo "$desc" | xargs)
  status_clean=$(echo "$status" | xargs)
  maps_to=$(echo "$maps_to" | xargs)
  
  # Map baseline Status to traceability status
  # "Confirmed" findings → not_started (ready to implement)
  # "Open" findings → not_started with note referencing open-questions.md
  traceability_status="not_started"
  notes=""
  if [ "$status_clean" = "Open" ]; then
    notes="Open Question - see open-questions.md"
  fi
  
  # Output: finding_id, requirement_ref (from Maps-To-Feature), empty impl/test refs, status, notes
  echo "$id,$maps_to,,,${traceability_status},${notes}"
done >> "$OUTPUT"

echo "Seeded $OUTPUT with $(tail -n +2 "$OUTPUT" | wc -l) findings from baseline inventory"
```

<task type="auto">
  <name>Create traceability query helpers</name>
  <files>scripts/traceability/query-matrix.sh</files>
  <action>
Create convenience script for common traceability matrix queries per FRD F13.1 requirements.

**scripts/traceability/query-matrix.sh:**

```bash
#!/bin/bash
set -euo pipefail

MATRIX=".planning/traceability-matrix.csv"

usage() {
  cat <<USAGE
Usage: $0 <command> [args]

Commands:
  gaps                 - Show all findings without tests (status != tested|verified)
  by-feature <FN>      - Show findings for feature (e.g., F7, F2.3)
  by-status <status>   - Show findings with given status
  open-questions       - Show findings marked as Open Questions
  coverage-summary     - Status breakdown by feature
  finding <BF-NNN>     - Show single finding details

Examples:
  $0 gaps
  $0 by-feature F7
  $0 by-status tested
  $0 open-questions
  $0 coverage-summary
  $0 finding BF-028
USAGE
  exit 1
}

[ $# -lt 1 ] && usage

CMD="$1"
shift || true

case "$CMD" in
  gaps)
    echo "Findings without tests (not_started or implemented):"
    tail -n +2 "$MATRIX" | grep -v ',tested,' | grep -v ',verified,' | cut -d, -f1,2,5
    ;;
  by-feature)
    [ -z "${1:-}" ] && { echo "Error: Feature ID required"; usage; }
    FEATURE="$1"
    echo "Findings for feature $FEATURE:"
    tail -n +2 "$MATRIX" | grep ",$FEATURE" | cut -d, -f1,2,5
    ;;
  by-status)
    [ -z "${1:-}" ] && { echo "Error: Status required"; usage; }
    STATUS="$1"
    echo "Findings with status=$STATUS:"
    tail -n +2 "$MATRIX" | grep ",$STATUS," | cut -d, -f1,2,5
    ;;
  open-questions)
    echo "Findings marked as Open Questions:"
    tail -n +2 "$MATRIX" | grep 'Open Question' | cut -d, -f1,2,6
    ;;
  coverage-summary)
    echo "Coverage summary by feature:"
    echo "Feature,not_started,implemented,tested,verified"
    for feature in F1 F2 F3 F4 F5 F6 F7 F8 F9 F10 F11 F12 F13; do
      not_started=$(tail -n +2 "$MATRIX" | grep ",$feature" | grep ',not_started,' | wc -l)
      implemented=$(tail -n +2 "$MATRIX" | grep ",$feature" | grep ',implemented,' | wc -l)
      tested=$(tail -n +2 "$MATRIX" | grep ",$feature" | grep ',tested,' | wc -l)
      verified=$(tail -n +2 "$MATRIX" | grep ",$feature" | grep ',verified,' | wc -l)
      echo "$feature,$not_started,$implemented,$tested,$verified"
    done
    ;;
  finding)
    [ -z "${1:-}" ] && { echo "Error: Finding ID required"; usage; }
    FINDING="$1"
    echo "Details for $FINDING:"
    head -1 "$MATRIX"
    tail -n +2 "$MATRIX" | grep "^$FINDING,"
    ;;
  *)
    echo "Error: Unknown command '$CMD'"
    usage
    ;;
esac
```

Make executable: `chmod +x scripts/traceability/query-matrix.sh`
