# Booking-Hub End-User Guide

## Introduction
Booking-Hub is a room and resource booking system. This guide covers day-to-day booking operations for end users.

## Getting Started
### Logging In
1. Navigate to Booking-Hub URL
2. Click "Login" → redirects to authentication page
3. Enter your credentials
4. After successful login, you'll land on the Calendar View

### Understanding the Interface
- **Calendar View**: Month/week grid showing all bookings with colour-coded locations
- **Day View**: Hourly slot view for single-day scheduling
- **List View**: Filterable table of all bookings

## Creating a Booking
### Quick Booking from Calendar
1. Click an empty slot in Calendar View
2. Form pre-fills with location and time from clicked slot
3. Add title, select resources, fill custom fields
4. Click "Save"
5. Confirmation banner shows status: "Pending approval" or "Approved" (depends on system settings)

### Understanding Auto-Approval
- If "Auto-approve bookings" is ON: Your booking is immediately approved
- If "Auto-approve bookings" is OFF: Your booking enters "Pending" status and requires manager approval

## Editing a Booking
### Single-Occurrence Edit
1. Click booking in calendar
2. Click "Edit" in detail modal
3. Make changes
4. Click "Save"
5. Confirmation banner confirms save

### Recurring Series Edit
For recurring bookings (e.g., weekly meetings):
1. Click any occurrence
2. Click "Edit"
3. Make changes, click "Save"
4. **Scope Confirmation Dialog** appears with two options:
   - "This occurrence only": Changes apply to ONLY this occurrence
   - "Entire series": Changes apply to ALL future occurrences
5. Select scope (required, no silent default)
6. Post-save summary banner confirms scope: "Only this occurrence was changed"

## Conflict Warnings
If your booking conflicts with another (same location or unique resource):
- **Conflict banner** appears showing conflicting booking ID and type (location/resource)
- **For non-approvers**: Save is blocked until conflict resolved (change time/location/resource)
- **For approvers** (users with approval permission): Conflict is a soft warning; can save with confirmation

## Approval Workflow (Approvers Only)
Users with approval permission see the "Approvals" menu item.

### Approving/Denying Bookings
1. Navigate to Approvals Queue
2. Table shows all pending bookings with conflict badges
3. Click "Approve" or "Deny"
4. Confirmation toast appears
5. Booking removed from queue (approved bookings appear in calendar, denied bookings do not)

## FAQ
- **Q: Can I delete a recurring series?** A: Yes, delete any occurrence and select "Entire series" scope.
- **Q: What happens if I book a conflicting slot?** A: See Conflict Warnings section above.
- **Q: How do I know if my booking needs approval?** A: Check status badge in booking detail modal or list view.

# Booking-Hub Admin Guide

## Introduction
This guide covers administrative configuration of Booking-Hub. Requires admin permissions.

## Admin Navigation
Admin section appears in sidebar (or bottom nav on mobile) only if you have admin permissions. Contains:
- Locations Admin
- Resources Admin
- Custom Fields Builder
- Users Admin
- Roles & Permissions Matrix
- Settings Admin
- Audit Log Viewer

## Location Management
### Creating a Location
1. Navigate to Admin > Locations
2. Click "Create Location"
3. Fill form:
   - **Name**: Required, displayed in booking calendar
   - **Colour**: Hex colour for calendar visual coding (e.g., #FF5733)
   - **Building**: Grouping metadata (optional)
   - **Layout**: Free-text layout description (optional)
4. Click "Save Location"
5. Confirmation banner appears

### Soft-Delete Behavior
- Deleting a location does NOT delete existing bookings
- Confirmation dialog: "Existing bookings will keep this location reference"
- Deleted locations hidden from create/edit forms but remain visible in historical booking data

## Resource Management
### Creating a Resource
1. Navigate to Admin > Resources
2. Click "Create Resource"
3. Fill form:
   - **Name**: Required (e.g., "Conference Phone")
   - **Type**: Classification (e.g., "Equipment", "Service")
   - **Description**: Optional details
   - **Is Unique**: Check if resource can only be used by ONE booking at a time
     - Enables resource-level conflict detection
     - Example: Conference phone is unique (only one group can use it), whiteboard is NOT unique (multiple rooms have whiteboards)
   - **Restrict Locations**: Multi-select locations this resource is available in
     - Empty = available to all locations
     - Selected locations = only those locations can use this resource
4. Click "Save Resource"

## Custom Field Configuration
### Creating Field Definitions
1. Navigate to Admin > Custom Fields > Field Definitions tab
2. Click "Create Field Definition"
3. Fill form:
   - **Name**: Field label shown in booking form (e.g., "Catering Headcount")
   - **Field Type**: textfield, select, textarea, radio, checkbox
   - **Options**: Required for select/radio/checkbox types (one option per line)
   - **Required**: Check if field must be filled
4. **Live Preview** shows how field renders
5. Click "Save"

### Creating Field Templates
Field templates control WHICH fields appear for WHICH locations:
1. Navigate to Field Templates tab
2. Click "Create Field Template"
3. **Context**: Select "Global" (all locations) or specific location
4. **Associated Fields**: Multi-select field definitions to include
5. Click "Save"

**Example:** "Catering Headcount" field only appears when booking the Conference Room (scoped template).

## User Management
### Creating Users
1. Navigate to Admin > Users
2. Click "Create User"
3. Fill form:
   - **Display Name**: User's visible name
   - **Email**: Required, unique, used for login
   - **Password**: Temporary password (user must change on first login)
   - **Roles**: Multi-select from 17 available roles (role_calendar_viewer, role_room_booking, etc.)
4. Click "Create User"
5. Confirmation: "User created — temporary password set"

### Admin vs Self Editing
- **Editing another user** (admin): Can change name, email, roles (NOT password)
- **Editing yourself** (self): Can only change name; email/roles require admin; password change via "My Account" page

## Settings Configuration
### Approval Workflow
- **approveBooking toggle**: ON = auto-approve new bookings, OFF = require manual approval
- **Propagation indicator**: Changes take effect immediately (no restart needed)

### Calendar Display
- **Slot size**: Time slot granularity in minutes (15, 30, 60)
- **Min/Max time**: Calendar start/end times (e.g., 08:00 - 18:00)

### Display & Feeds
- **Preview Display Board**: Opens public display board in new tab
- **Copy feed links**: Shows RSS2/iCal/JSON feed URLs for external calendar subscription

## Audit Log
### Viewing Change History
1. Navigate to Admin > Audit Log
2. **Filters**: Entity type, actor, date range
3. **Export to CSV**: Downloads filtered audit entries
4. **Deep-linking**: Booking detail modals link directly to booking's audit history

**Immutable records**: Audit entries cannot be edited or deleted (read-only compliance trail).

## FAQ
- **Q: Can I bulk-import locations/resources?** A: Not currently supported (v2.0 scope limitation).
- **Q: How do I reset a user's password?** A: Via Users Admin > Edit user (admin only).
- **Q: Where do I configure roles?** A: Roles & Permissions Matrix is read-only; edit in Keycloak Admin Console.

**HelpTooltip.tsx — Reusable tooltip component:**
```typescript
import { useState } from 'react';
import { QuestionMarkCircleIcon } from '@heroicons/react/24/outline'; // Or similar icon library

interface HelpTooltipProps {
  content: string;
  position?: 'top' | 'right' | 'bottom' | 'left';
}

export function HelpTooltip({ content, position = 'right' }: HelpTooltipProps) {
  const [visible, setVisible] = useState(false);

  return (
    <span className="help-tooltip-wrapper" onMouseEnter={() => setVisible(true)} onMouseLeave={() => setVisible(false)}>
      <QuestionMarkCircleIcon className="h-4 w-4 text-gray-400 cursor-help" />
      {visible && (
        <div className={`help-tooltip-popover ${position}`}>
          {content}
        </div>
      )}
    </span>
  );
}
```
