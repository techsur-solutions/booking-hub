Output: Fully functional Custom Field Builder with Definitions/Templates tabs, live field preview, options validation, and Playwright tests.

**customFieldsApi.ts** — API client methods:
```typescript
export const customFieldsApi = {
  getDefinitions: () => apiClient.get<CustomField[]>('/custom-fields'),
  getDefinitionById: (id: string) => apiClient.get<CustomField>(`/custom-fields/${id}`),
  createDefinition: (data: CustomFieldCreateRequest) => apiClient.post<CustomField>('/custom-fields', data),
  updateDefinition: (id: string, data: CustomFieldUpdateRequest) => apiClient.put<CustomField>(`/custom-fields/${id}`, data),
  deleteDefinition: (id: string) => apiClient.delete(`/custom-fields/${id}`),
  
  getTemplates: () => apiClient.get<FieldTemplate[]>('/field-templates'),
  getTemplateById: (id: string) => apiClient.get<FieldTemplate>(`/field-templates/${id}`),
  createTemplate: (data: FieldTemplateCreateRequest) => apiClient.post<FieldTemplate>('/field-templates', data),
  updateTemplate: (id: string, data: FieldTemplateUpdateRequest) => apiClient.put<FieldTemplate>(`/field-templates/${id}`, data),
  deleteTemplate: (id: string) => apiClient.delete(`/field-templates/${id}`)
};
```

  <files>frontend/src/components/admin/CustomFieldForm.tsx, frontend/src/components/admin/FieldPreview.tsx</files>
  <action>
Create single-page form for field definitions with live preview per UI-ADMIN-03.

**CustomFieldForm.tsx** — Field definition Create/Edit form:
- Fields per Phase 4 schema (F0-confirmed 5-value enum from Plan 04-04):
  - `name` (text input, required, max 255 chars)
  - `field_type` (dropdown with 5 options: textfield, select, textarea, radio, checkbox)
  - `required` (checkbox, boolean, defaults to false)
  - `options` (textarea, one option per line; shown ONLY when field_type is select/radio/checkbox)
- Options validation per Phase 4 Plan 04-04 deliberate improvement:
  - **Rule 1:** If field_type is select/radio/checkbox, `options` MUST have at least one value (enforce client-side before submit)
  - **Rule 2:** If field_type is textfield/textarea, `options` MUST be empty (hide options input entirely for these types)
  - Show validation error if user tries to submit select/radio/checkbox with empty options
- Live preview: render FieldPreview component below form, updates in real-time as user changes field_type or options
- On successful save: show StateConfirmationBanner, refresh Definitions table

**FieldPreview.tsx** — Live field rendering component:
- Props: `field_type`, `options`, `label` (uses field name as preview label)
- Renders preview based on field_type:
  - `textfield` → `<input type="text" placeholder="Text input preview" disabled />`
  - `textarea` → `<textarea placeholder="Textarea preview" disabled />`
  - `select` → `<select disabled><option>Choose...</option>{options.map(opt => <option>{opt}</option>)}</select>`
  - `radio` → Radio button group with each option as a radio input (disabled)
  - `checkbox` → Checkbox group with each option as a checkbox input (disabled)
- Preview is read-only (disabled state) to indicate it's a preview, not a functional form field
