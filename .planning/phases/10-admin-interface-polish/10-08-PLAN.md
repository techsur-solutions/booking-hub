  <what-built>
Wave 1 Plans (10-01 through 10-07) implemented all admin CRUD screens and Phase 9 implemented core booking views. Desktop responsive CSS (from Phase 9 Plan 01 layout.css) applies sidebar-always-visible, full calendar grid, and multi-column table layouts at >1024px breakpoints.
  </what-built>
  <how-to-verify>
**Manual testing at desktop resolutions:**

1. **Open browser at 1280px viewport:**
   - Chrome DevTools → Responsive mode → Custom 1280 x 1024
   - Navigate to `http://localhost:3000/bookings?view=month` (Calendar View)

2. **Verify sidebar always visible:**
   - Assert: Sidebar is fixed on left side (NOT collapsed, NO hamburger menu)
   - Assert: Sidebar shows all nav items (Calendar, Approvals if role present, Feeds, Admin section, My Account)
   - Assert: Sidebar width ~240px, does not overlap main content

3. **Verify full calendar grid (Phase 9 Plan 05):**
   - Navigate to Calendar View (`/bookings?view=month`)
   - Assert: FullCalendar month grid shows 4-5 weeks simultaneously
   - Assert: All 7 days (Mon-Sun) visible without horizontal scroll
   - Assert: Event titles readable (not truncated to unreadable length)

4. **Verify admin tables show all columns (Plan 10-01, 10-02):**
   - Navigate to Locations Admin (`/admin/locations`)
   - Assert: Table shows Name, Colour, Building, Layout, Actions columns ALL visible without horizontal scroll
   - Navigate to Resources Admin (`/admin/resources`)
   - Assert: Table shows Name, Type, Description, Is Unique, Restrict Locations, Actions columns ALL visible without horizontal scroll

5. **Verify forms use appropriate column layout:**
   - Navigate to Locations Create form (`/admin/locations/new`)
   - Assert: Form fields use two-column layout where appropriate (e.g., name + class on one row, colour + building on another row)
   - Assert: Form fits within viewport without vertical scroll for above-fold fields

6. **Repeat verification at 1920px viewport:**
   - Change DevTools viewport to 1920 x 1080
   - Re-verify sidebar visible, calendar grid full, admin tables all columns visible
   - Assert: No excessive whitespace (layout scales appropriately to wider screen)

**Success signal:** Sidebar always visible, calendar shows 4-5 weeks, admin tables show all columns, forms use multi-column layout, NO horizontal scroll on any admin screen.
  </how-to-verify>
  <resume-signal>Type "approved" to continue, or describe any layout issues found (e.g., "sidebar collapses at 1280px", "admin table columns cut off")</resume-signal>
</task>
