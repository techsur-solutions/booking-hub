**SoftDeleteDialog.tsx** — Reusable confirmation dialog for soft-delete operations:
- Props: `open`, `onConfirm`, `onCancel`, `entityName`, `contextMessage`
- Renders: "Delete {entityName}?" title, contextMessage body ("Existing bookings will keep this location reference"), Confirm/Cancel buttons
- onConfirm triggers `locationsApi.delete(id)` calling `DELETE /locations/:id` (soft-delete endpoint from Phase 4)

**locationsApi.ts** — API client methods:
```typescript
export const locationsApi = {
  getAll: () => apiClient.get<Location[]>('/locations'),
  getById: (id: string) => apiClient.get<Location>(`/locations/${id}`),
  create: (data: LocationCreateRequest) => apiClient.post<Location>('/locations', data),
  update: (id: string, data: LocationUpdateRequest) => apiClient.put<Location>(`/locations/${id}`, data),
  delete: (id: string) => apiClient.delete(`/locations/${id}`) // soft-delete
};
```

  - `description` (textarea, optional)

- Inline validation: name required, colour must be valid hex (#RRGGBB or #RGB format)
- Submit button: "Save Location"
- On successful save: show StateConfirmationBanner ("Location saved at [timestamp]"), navigate back to `/admin/locations`

**ColourPicker.tsx** — Reusable component for hex colour selection:
- Dual input: text field for manual hex entry + visual swatch showing current colour
- Optional: native browser `<input type="color">` fallback for visual picker
- Validates hex format on blur, shows error if invalid
- Props: `value: string`, `onChange: (hex: string) => void`, `label?: string`

**LocationCreate.tsx** — Route page for `/admin/locations/new`:
- Renders LocationForm with no initial values
- On submit: calls `locationsApi.create()`

**LocationEdit.tsx** — Route page for `/admin/locations/:id/edit`:
- Fetches location by id via `locationsApi.getById()`
- Renders LocationForm pre-filled with existing values
- On submit: calls `locationsApi.update(id, data)`
