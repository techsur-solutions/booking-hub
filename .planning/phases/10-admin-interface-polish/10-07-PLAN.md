Create Audit Log Viewer page per UX-Mockup Navigation Map: `/admin/audit-log` route.

**AuditLogViewer.tsx** — Page shell with:
- Header: "Audit Log" + "Export to CSV" button (top-right)
- AuditLogFilters component (below header, horizontal filter bar)
- AuditLogTable component (main content)
- Immutable record notice: "Audit entries are read-only and cannot be edited or deleted." (icon + text, positioned near header)
- Deep-link support: Parse URL query params `?entity_type=booking&entity_id=X` (passed from Booking Detail Modal "View history" link) and pre-populate filters

**AuditLogFilters.tsx** — Filter controls per UI-ADMIN-07:
- `entity_type` (dropdown with options: "All", "booking", "location", "resource", "custom_field", "user", "role", "settings", per Phase 6 Plan 04 DomainEventParser entity types)
- `actor` (text search input, searches by actor name or email)
- `start_date` (date picker, defaults to 30 days ago)
- `end_date` (date picker, defaults to today)
- "Apply Filters" button triggers fetch with current filter values
- "Clear Filters" button resets to defaults

**AuditLogTable.tsx** — Read-only table with columns per UI-ADMIN-07:
- Timestamp (datetime, sortable, format: "YYYY-MM-DD HH:mm:ss")
- Actor (user name or email, from `actor_id` lookup)
- Entity Type (booking, location, resource, etc.)
- Entity ID (UUID, truncated with tooltip showing full ID)
- Action (created, updated, deleted, approved, denied, etc., from `action_type` field)
- Before/After (optional columns, only shown when data available per Phase 6 Plan 03 additive V2 migration — NOTE: Phase 6 audit_log_entries table has NO before/after value columns per F0 audit BF-106, only message+data free text; UI should show "N/A" for these columns unless future enhancement adds structured diff)

NO action buttons (Edit/Delete) on rows — table is strictly read-only, emphasizing immutability per F11 principle.

Fetch via `auditLogApi.getFiltered({ entity_type, actor_id, start_date, end_date })` calling v1.0 backend `GET /audit-log?entity_type=X&start_date=Y&end_date=Z` per Phase 6 Plan 04.

**auditLogApi.ts** — API client methods:
```typescript
export const auditLogApi = {
  getFiltered: (params: AuditLogFilters) => apiClient.get<AuditLogEntry[]>('/audit-log', { params }),
  exportCsv: (params: AuditLogFilters) => apiClient.get('/audit-log/export', { params, responseType: 'blob' }) // Assumes backend provides CSV export endpoint
};
```
