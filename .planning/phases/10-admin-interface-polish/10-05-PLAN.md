<objective>
Implement the Role & Permission Matrix as a read-only visualization of the 17 permission flags across all Keycloak roles, highlighting deny-by-default permissions and providing a direct link to Keycloak Admin for actual editing — so admins understand the current permission landscape without exposing inline editing that would bypass Keycloak's RBAC governance.

Purpose: Permission assignment is governed by Keycloak; the UI provides visibility and audit capability, not a parallel editing surface that could diverge from the source of truth.
Output: Read-only permission matrix grid with roles × permissions checkmarks, deny-by-default highlights, Keycloak link, and Playwright tests.
</objective>
