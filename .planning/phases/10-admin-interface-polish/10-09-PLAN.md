<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Wave 1 Plans (10-01 through 10-07) implemented all admin CRUD screens. Phase 9 Plan 01 implemented responsive sidebar that collapses at tablet breakpoint with hamburger menu toggle.
  </what-built>
  <how-to-verify>
**Manual testing at tablet resolutions:**

1. **Open browser at 768px viewport (iPad portrait):**
   - Chrome DevTools → Responsive mode → 768 x 1024
   - Navigate to `http://localhost:3000/bookings?view=month`

2. **Verify collapsible sidebar with hamburger menu:**
   - Assert: Sidebar is collapsed by default (NOT always visible like desktop)
   - Assert: Hamburger menu icon visible in header (top-left or near logo)
   - Click hamburger icon
   - Assert: Sidebar slides in/overlays main content (does NOT push content, uses overlay/drawer pattern)
   - Assert: Sidebar shows all nav items when expanded
   - Click outside sidebar or close icon
   - Assert: Sidebar collapses again

3. **Verify calendar shows 2-3 weeks:**
   - Navigate to Calendar View (`/bookings?view=month`)
   - Assert: FullCalendar month grid shows 2-3 weeks (NOT full 4-5 weeks from desktop)
   - Assert: Calendar is readable, events not excessively truncated

4. **Verify admin tables horizontal scroll:**
   - Navigate to Locations Admin (`/admin/locations`)
   - Assert: Table allows horizontal scroll (swipe left/right on touch device or use scrollbar)
   - Assert: All columns (Name, Colour, Building, Layout, Actions) accessible via scroll (NOT hidden entirely)
   - Assert: Table header scrolls with content (sticky header desirable but not required)

5. **Verify forms stack to single column:**
   - Navigate to Locations Create form (`/admin/locations/new`)
   - Assert: Form fields stack vertically (one field per row, NOT two-column layout from desktop)
   - Assert: Input fields expand to full width (touch-friendly tap targets)

6. **Repeat verification at 1024px viewport (tablet landscape):**
   - Change DevTools viewport to 1024 x 768
   - Re-verify sidebar collapsible (still uses hamburger, NOT always-visible like >1024px desktop)
   - Re-verify calendar shows 2-3 weeks, tables scroll horizontally

**Success signal:** Sidebar collapsible via hamburger menu, calendar shows 2-3 weeks, admin tables scroll horizontally (all columns accessible), forms single-column layout.
  </how-to-verify>
  <resume-signal>Type "approved" to continue, or describe any layout issues found (e.g., "sidebar always visible at 1024px instead of collapsible", "table columns completely hidden")</resume-signal>
</task>
