<task type="auto">
  <name>Task 2: Permission-gated Edit/Delete/Clone actions</name>
  <files>frontend/src/components/booking/BookingDetailModal.tsx</files>
  <action>
Add action buttons in modal footer:

**Edit button:**
- Permission check: user is booking owner (booking.created_by === currentUser.id) OR user has admin permission
- Click → navigate to /bookings/{booking.id}/edit (opens BookingEdit page)
- Hidden (not disabled) if user lacks permission (deny-by-default per UI-PATTERN-03)

**Delete button:**
- Same permission check as Edit (owner OR admin)
- Click → show confirmation dialog: "Delete this booking? This cannot be undone."
- If recurring booking → show additional warning: "This is a recurring booking. Delete this occurrence only or entire series?"
  - Two delete options: "This occurrence only", "Entire series"
- On confirm: DELETE /bookings/{id}?scope={scope}
- On 204 success: show toast "Booking deleted", close modal, trigger parent view refresh (emit onDeleted callback)
- Hidden if user lacks permission

**Clone button:**
- No permission check (any authenticated user can clone)
- Click → navigate to /bookings/create with pre-fill params from current booking:
  - ?title={title} (Copy)
  - &location_id={location_id}
  - &start_time={start_time + 1 day}
  - &end_time={end_time + 1 day}
  - &resource_ids={resource_ids}
  - Custom field values NOT pre-filled (user re-enters)
- Clone does NOT copy recurrence_pattern (clone creates single booking)

From TechArch-BookingHub.md §4.2.4:
```typescript
DELETE /bookings/:id?scope=this-only|entire-series
Response (204): No Content
```

Permission check implementation:
```typescript
const currentUser = useCurrentUser(); // from useAuth hook
const canEdit = booking.created_by === currentUser.id || currentUser.roles.includes('role_admin');
```
