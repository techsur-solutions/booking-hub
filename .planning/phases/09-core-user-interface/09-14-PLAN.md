<objective>
Implement Display Board (full-screen kiosk mode for approved bookings) and Feed Subscription UI (RSS2/iCal/JSON URL listing with copy buttons), providing public surfaces for external calendar integration and digital signage.

Purpose: Display Board enables digital signage deployments showing only approved bookings. Feed Subscription allows users to subscribe to bookings in external calendars (Outlook, Google Calendar, etc.) via RSS2/iCal/JSON feeds.
Output: Working Display Board with auto-refresh and approved-only guarantee, working Feed Subscription page with copy-to-clipboard functionality.
</objective>
