2. Add a header div above the view tabs containing:
   - Left side: existing view tabs
   - Right side: "Create Booking" button styled as primary action

**Specific changes:**

```typescript
// Add after imports
import { useSearchParams } from 'react-router-dom'; // already imported

// Inside BookingsView component, extract current date for pre-fill
const currentDate = searchParams.get('date') ?? '';

// Modify JSX structure to add header with button
return (
  <div className="bookings-workspace">
    {/* Header with view tabs and create button */}
    <div className="bookings-header" style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginBottom: 'var(--spacing-md)' }}>
      {/* View switcher tabs */}
      <div className="bookings-tabs" role="tablist" aria-label="Booking view">
        {/* existing tab buttons */}
      </div>
      
      {/* Create Booking button */}
      <Link 
        to={`/bookings/create${currentDate ? `?start_time=${currentDate}T09:00` : ''}`}
        className="btn btn--primary"
        data-testid="create-booking-button"
      >
        + Create Booking
      </Link>
    </div>

    {/* View content - unchanged */}
    <div className="bookings-content" role="tabpanel">
      {view === 'month' && <CalendarView />}
      {view === 'day' && <DayView />}
      {view === 'list' && <ListView />}
    </div>
  </div>
);
```

**Styling notes:**
- Use existing `btn btn--primary` classes from tokens.css (established in 09-04)
- Button should be visually prominent but not overwhelming
- Pre-fill start_time with current date at 9am if date param exists (user-friendly default)

**Why this fixes the gap:**
Currently the route `/bookings/create` exists (plan 09-09) but there's no UI element linking to it. Users can only reach it by typing the URL manually or via calendar slot click (which wasn't implemented). This button provides the primary navigation path.

```typescript
test.describe('Create Booking Button Navigation - UAT Gap #6', () => {
  test.beforeEach(async ({ page }) => {
    // Mock API endpoints (same pattern as existing tests)
    await page.route('http://localhost:8080/bookings**', async (route) => {
      await route.fulfill({ json: { bookings: [] } });
    });
    await page.route('http://localhost:8080/locations**', async (route) => {
      await route.fulfill({ json: [
        { id: 'loc-a', name: 'Conference Room A', colour: '#3498db', building: 'Main' }
      ] });
    });
    await page.route('http://localhost:8080/resources**', async (route) => {
      await route.fulfill({ json: [] });
    });
    
    // Set E2E roles
    await page.addInitScript(() => {
      window.__E2E_ROLES__ = ['role_calendar_viewer', 'role_room_booking'];
    });
  });

  test('Create Booking button appears on BookingsView', async ({ page }) => {
    await page.goto('http://localhost:5173/bookings?view=month');
    await expect(page.getByTestId('create-booking-button')).toBeVisible();
    await expect(page.getByTestId('create-booking-button')).toHaveText(/Create Booking/);
  });

  test('Create Booking button navigates to /bookings/create', async ({ page }) => {
    await page.goto('http://localhost:5173/bookings?view=month');
    await page.getByTestId('create-booking-button').click();
    await expect(page).toHaveURL(/\/bookings\/create/);
    
    // Verify booking form loaded (reuses existing page selectors)
    await expect(page.locator('[data-testid="booking-form"]')).toBeVisible();
  });

  test('Create Booking button preserves date as start_time param', async ({ page }) => {
    await page.goto('http://localhost:5173/bookings?view=month&date=2024-03-15');
    await page.getByTestId('create-booking-button').click();
    await expect(page).toHaveURL(/\/bookings\/create\?start_time=2024-03-15/);
  });
});
```
