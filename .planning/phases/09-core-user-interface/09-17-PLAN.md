**Gap Reference:** UAT Test #6 reported "new bookings page does not have any locations so I am not able to create one" (blocker severity).

**Root cause investigation:**
The location dropdown is empty, which suggests one of:
1. API call failing due to authentication (JWT token not attached or expired)
2. API returning empty array (backend issue or no seed data)
3. React Query caching issue preventing refetch
4. CORS or network error blocking request

**Fix approach:**

**Step 1: Verify API client JWT interceptor**

Check `frontend/src/api/client.ts` for proper JWT token attachment:

```typescript
// Expected pattern from 09-02-SUMMARY.md
import { keycloak } from '../auth/keycloak';

apiClient.interceptors.request.use(
  async (config) => {
    if (keycloak.authenticated) {
      const token = keycloak.token;
      if (token) {
        config.headers.Authorization = `Bearer ${token}`;
      }
    }
    return config;
  },
  (error) => Promise.reject(error)
);
```

**Verify:**
- Keycloak token is valid when BookingCreate mounts
- Token refresh happens if expired (keycloak.updateToken())
- Authorization header is attached to ALL requests

**Step 2: Add retry logic to useLocations hook**

Modify `frontend/src/hooks/useLocations.ts` to handle transient failures:

```typescript
export function useLocations(params?: { include_deleted?: boolean }) {
  return useQuery({
    queryKey: ['locations', params],
    queryFn: async () => {
      // Ensure token is fresh before API call
      await keycloak.updateToken(30); // Refresh if expires within 30s
      return locationsApi.getLocations(params).then((res) => res.data);
    },
    retry: 2, // Retry failed requests 2 times
    staleTime: 5 * 60 * 1000, // Cache for 5 minutes (same pattern as useSettings from 09-02)
  });
}
```

**Step 3: Add error logging for debugging**

Add console.error in the hook to capture API failures:

```typescript
queryFn: async () => {
  try {
    await keycloak.updateToken(30);
    const response = await locationsApi.getLocations(params);
    console.log('[useLocations] Fetched', response.data.length, 'locations');
    return response.data;
  } catch (error) {
    console.error('[useLocations] API call failed:', error);
    throw error;
  }
},
```

**Step 4: Verify BookingForm handles empty/loading/error states**

Check `frontend/src/components/booking/BookingForm.tsx` location dropdown:

```typescript
const { data: locations = [], isLoading: locationsLoading, isError: locationsError } = useLocations();

// Show loading state
{locationsLoading && <div>Loading locations...</div>}

// Show error state
{locationsError && <div className="error">Failed to load locations. Please refresh.</div>}

// Show empty state
{!locationsLoading && !locationsError && locations.length === 0 && (
  <div className="warning">No locations available. Contact admin.</div>
)}

// Render dropdown only if locations exist
{locations.length > 0 && (
  <select name="location_id" required>
    <option value="">Select location</option>
    {locations.map(loc => (
      <option key={loc.id} value={loc.id}>{loc.name}</option>
    ))}
  </select>
)}
```

- User can select a location and proceed with booking creation
