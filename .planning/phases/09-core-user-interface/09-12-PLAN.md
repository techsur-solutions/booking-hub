  <files>frontend/src/components/booking/ConflictBanner.tsx</files>
  <action>
Refactor ConflictWarning (from 09-09) into ConflictBanner with enhanced UI.

Props:
```typescript
interface ConflictBannerProps {
  conflicts: Array<{
    booking_id: string;
    booking_title: string;
    conflict_type: 'location' | 'resource';
    resource_id?: string;
    resource_name?: string;
  }>;
  userHasApprovePermission: boolean;
  onSaveAnyway?: () => void; // callback for approvers
}
```

Rendering:

**If conflicts.length === 0:** render nothing

**If conflicts.length > 0 AND userHasApprovePermission === false (hard-block):**
- Red banner with icon: "⚠️ Conflict detected - Cannot save"
- Message: "This booking conflicts with existing bookings. Resolve conflicts to proceed."
- List conflicts grouped by type:
  - **Location conflicts:** "Location conflict with:"
    - {booking_title} (ID: {booking_id}) — {start_time} to {end_time}
  - **Resource conflicts:** "Resource conflict ({resource_name}) with:"
    - {booking_title} (ID: {booking_id})
- Each booking ID is a clickable link opening BookingDetailModal
- "What now?" help text: "Change the time, location, or resources to avoid conflicts."
- Save button in parent form is DISABLED via `disabled={conflicts.length > 0 && !userHasApprovePermission}`

**If conflicts.length > 0 AND userHasApprovePermission === true (soft-warn):**
- Yellow banner with icon: "⚠️ Warning - Conflicts detected"
- Message: "This booking conflicts with existing bookings. As an approver, you can save anyway."
- Same conflict list (grouped by type, clickable IDs)
- "Save Anyway" button at bottom of banner (distinct from main Save button)
- Clicking "Save Anyway" shows confirmation dialog: "Create booking despite conflicts? This will result in a double-booking."
- On confirm: calls onSaveAnyway callback (parent handles actual save)

Visual styling:
- Hard-block banner: red background (#FEE2E2), red border, red text
- Soft-warn banner: yellow background (#FEF3C7), yellow border, dark text
- Conflict type icons: location = 📍, resource = 🔧
- Booking ID links: underlined, hover shows booking title tooltip
